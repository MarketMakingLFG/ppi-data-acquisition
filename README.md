# PPI Data Acquisition

This public repository is the acquisition boundary for PPI evidence.

It may retrieve bounded provider responses, record timestamps and hashes, and package immutable candidate artifacts for private review.

It may not curate or semantically approve evidence, calculate private features or scores, decide countability, mutate the private registry, dispatch private workflows, or authorize production, broker, order, trading, MMM, raw-data, or R12 actions.

The initial workflow is manual-only. Scheduled execution and private-repository dispatch are intentionally disabled.
